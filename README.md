# CosyVoice 3: Оптимизированный русский синтез речи и пайплайн озвучки аудиокниг

[![GitHub repository](https://img.shields.io/badge/GitHub-NKostylev2%2Fmycosyvoice3setup-blue.svg)](https://github.com/NKostylev2/mycosyvoice3setup)
[![Python 3.10+](https://img.shields.io/badge/Python-3.10%2B-green.svg)](https://www.python.org/)
[![Model Fun-CosyVoice3-0.5B](https://img.shields.io/badge/Model-Fun--CosyVoice3--0.5B-orange.svg)](https://github.com/FunAudioLLM/CosyVoice)
[![Sample Rate 24kHz](https://img.shields.io/badge/Sample%20Rate-24000%20Hz-purple.svg)]()

Проект содержит готовую production-конфигурацию, скрипты и пайплайн для качественного синтеза русской речи моделью **CosyVoice 3 (0.5B)**. 

Репозиторий решает главные проблемы синтеза русской речи в оригинальном CosyVoice:
- **Проглатывание окончаний и последних слогов слов** диктором;
- Некорректное разбиение длинного текста встроенным китайским/английским фронтендом;
- Защита от обрезки хвоста аудиофайла при кодировании в MP3;
- Пакетная озвучка целых глав художественных произведений и аудиокниг (с контролем пауз между предложениями и абзацами);
- Бесшовный перемонтаж и локальное исправление отдельных реплик.

## 🚀 Ключевые особенности и исправления

### 1. Токенизаторное разбиение текста (`SentenceSegmenter`)
Встроенный фронтенд CosyVoice 3 рассчитан на китайский и английский языки. При синтезе русского текста он может ломать слова и фразы.
В модуле [`fanfic_pipeline/segmenter.py`](fanfic_pipeline/segmenter.py) реализован интеллектуальный сегментатор:
- Использует токенизатор модели (Qwen2 / `CosyVoice-BlankEN`) и библиотеку `razdel.sentenize`.
- Сохраняет букву **Ё**, кавычки, тире и авторскую пунктуацию.
- Объединяет короткие предложения в смысловые речевые блоки по **60–80 токенов** (оптимальная длина контекста для CosyVoice 3).
- Исключает блоки короче 35 токенов, устраняя предупреждение `len(text) < 0.5 * len(prompt_text)` и предотвращая раннее срабатывание токена конца последовательности (EOS).

### 2. Параметры инференса без проглатывания звуков
- `text_frontend=False` — отключает ломающий русские окончания фронтенд.
- `stream=False` — генерация всего блока целиком без дрожания сэмплов в потоковых чанках.
- `speed=1.0` — естественная скорость речи без механических артефактов растяжения.
- Специальный промпт формата:  
  `prompt_text = f"You are a helpful assistant.<|endofprompt|>{ref_transcript}"`

### 3. Режиссерский монтаж и тайминги пауз
- Пауза между предложениями внутри абзаца: **200 мс**.
- Пауза между абзацами: **500 мс**.
- Пауза после заголовков глав: **500–700 мс**.
- **500 мс цифровой тишины в хвосте итогового файла**: предотвращает срезание последних слогов кодировщиком LAME MP3 и аудиоплеерами.

## 🛠️ Установка и запуск

### Требования
- **ОС:** Windows 10/11 или Linux
- **GPU:** NVIDIA с поддержкой CUDA (от 6–8 ГБ VRAM для комфортной работы)
- **Python:** 3.10 или 3.11
- **FFmpeg:** установлен и доступен в `PATH`

### Создание окружения

```powershell
# 1. Клонирование репозитория
git clone https://github.com/NKostylev2/mycosyvoice3setup.git
cd mycosyvoice3setup

# 2. Создание виртуального окружения
python -m venv cosyvoice_env
cosyvoice_env\Scripts\activate

# 3. Установка PyTorch с поддержкой CUDA (пример для CUDA 12.1/12.4)
pip install torch torchaudio --index-url https://download.pytorch.org/whl/cu121

# 4. Установка зависимостей
pip install -r requirements.txt

# 5. Клонирование базового репозитория CosyVoice и Matcha-TTS
git clone --recursive https://github.com/FunAudioLLM/CosyVoice.git
cd CosyVoice\third_party\Matcha-TTS
pip install -e .
cd ..\..
```

### Загрузка модели
Скачайте веса модели `Fun-CosyVoice3-0.5B` из ModelScope или HuggingFace:
```powershell
# Через git lfs или modelscope CLI
pip install modelscope
python -c "from modelscope import snapshot_download; snapshot_download('iic/CosyVoice3-0.5B', local_dir='CosyVoice/pretrained_models/Fun-CosyVoice3-0.5B')"
```

## 📖 Инструкция по использованию

### 1. Генерация главы или фанфика
Для синтеза книги или отдельной главы запустите скрипт:
```powershell
python scripts\generate_chapter_vid_voice.py
```
Скрипт выполняет:
1. Загрузку текста из `.docx` или `.txt`.
2. Разбиение на речевые блоки по 60–80 токенов без разрыва предложений.
3. Поэтапный синтез с кэшированием каждого сегмента в `output/.../segments/`.
4. Склейку всех фрагментов с правильными паузами (200 мс / 500 мс) и 500 мс хвостовой тишиной.
5. Экспорт мастер-WAV (24 кГц) и конвертацию в MP3 (128 kbps и 48 kbps mono).

### 2. Интерактивная Web-панель (Gradio WebUI)
Для интерактивной озвучки текста и клонирования голоса по 3-секундному образцу:
```powershell
# Запуск через готовый батник
cosyvoice_patches\start_cosyvoice_webui.bat

# Либо через python напрямую:
python cosyvoice_patches\webui_russian.py --port 50000 --model_dir CosyVoice/pretrained_models/Fun-CosyVoice3-0.5B
```
Интерфейс откроется по адресу `http://localhost:50000`.

### 3. Верификация качества окончаний (Whisper)
Для автоматической проверки, не обрезаны ли окончания в тестовом или сгенерированном файле:
```powershell
python scripts\test_endings_verification.py
```
Скрипт использует `whisper` с пословным выравниванием (`word_timestamps=True`) и проверяет длительность речевой паузы в конце файла.

### 4. Перемонтаж и бесшовная замена фрагментов
Если в длинной главе нужно переделать одно слово или фразу (например, заменить «Пролог II» на «Глава вторая»):
Не требуется перегенерировать всю главу целиком! Достаточно сгенерировать заменяемую фразу и выполнить автоматический перемонтаж:
```powershell
python scripts\remontage_seg0_prologue2.py
```
Скрипт находит границу тишины по RMS-энергии, накладывает 10-мс сглаживание (crossfade) и моментально пересобирает мастер-аудио.
